## Current issue and fix

The user reported that sending an approved outreach draft failed. Mailpit rejected the SMTP message because most insurer rows had an empty `agent_email`, resulting in an invalid `To` recipient.

The implemented fix preserves configured addresses, but when an insurer contact is blank it derives a deterministic local address in the format `insurer-<normalized-id>@insurer.assura.local`. The resolved recipient is used in the outreach UI/API/send route, and the mail simulator uses the same fallback for replies. SMTP remains restricted to Mailpit on port 1025; no external delivery is allowed.
